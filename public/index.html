다른 사람이 수동 최신화를 남용할 수 있나요? (절대 불가능)

GitHub Actions의 수동 실행(`workflow_dispatch`)은 저장소 소유자(DaramGC 계정)로 로그인된 브라우저에서만 실행 권한이 있습니다. 일반 방문자나 외부인이 GitHub 저장소에 접속하더라도 [Run workflow] 버튼이 전혀 보이지 않으므로 비용 및 API 키 남용 위험은 0%입니다.

원할 때 즉시 최신화하는 방법:

방법 1: GitHub에서 [Run workflow] 클릭 (저장소 소유자 전용)

아래 버튼을 눌러 GitHub Actions 페이지로 이동한 뒤 [Run workflow]를 클릭하시면 1분 만에 최신 인기 종목과 뉴스가 크롤링되어 업데이트됩니다.

방법 2: 화면 새로고침
