방법 1: GitHub에서 [Run workflow] 원클릭 실행 (가장 추천)

저장소의 Actions 워크플로우 페이지로 이동하여 [Run workflow]를 누르면 1분 내로 최신 뉴스와 시세를 즉시 수집·분석하여 웹에 반영합니다.

GitHub Actions 수동 실행 페이지 열기
방법 2: 화면 새로고침

이미 Actions 봇이 업데이트한 최신 데이터를 브라우저 캐시 없이 즉시 화면에 다시 로드하려면 상단의 [화면 새로고침] 버튼을 누르시면 됩니다.
